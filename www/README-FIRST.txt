SONGSEED — RELEASE 1.0
Fair Music Productions

WHAT'S INCLUDED
index.html — SongSeed web app (includes the offline rhyme dictionary)
manifest.webmanifest — installation information
sw.js — offline cache for the installed web app
icons/ — app icons

INSTALL ON A WEBSITE
Upload the contents of this folder to the root of a GitHub Pages repository (or any HTTPS web host).
For GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root).
Open the published HTTPS URL on your phone.
On Android Chrome: menu > Install app / Add to Home screen.
On iPhone Safari: Share > Add to Home Screen.

DESKTOP USE
Open the separate SongSeed_Standalone_1_0.html file in a desktop browser. It needs no web host.

YOUR DATA
Saved Seeds are stored locally in each browser/device, not in GitHub or a cloud account.
Use Saved Seeds > Export to make a backup. Test importing it before relying on it.
Deleting browser/site data, switching browser, or changing the site address can make local favorites unavailable.
Backups are important. There is no cross-device synchronization.

NOTES
The rhyme dictionary is pronunciation-based and may include unusual names and uncommon words.
The idea generator is a creative prompt tool, not a guarantee of unique or publishable titles.
This is the first release candidate. Test saving, export/import, and offline reopening on each target device.
Pronunciation data derived from CMU Pronouncing Dictionary, distributed with PocketSphinx.
